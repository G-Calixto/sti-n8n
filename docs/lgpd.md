# Termo LGPD simplificado para uso academico

Este sistema e um prototipo academico de Sistema Tutor Inteligente.

Ao utilizar a ferramenta, o professor declara estar ciente de que:

- as imagens enviadas devem evitar dados pessoais dos alunos;
- o uso e destinado a pesquisa e avaliacao do prototipo;
- o sistema envia a imagem para processamento por workflows do n8n e servicos de IA configurados no ambiente;
- as imagens nao sao salvas permanentemente pelo backend deste MVP;
- os resultados gerados pela IA devem ser revisados pelo professor antes de qualquer uso pedagogico.

O professor deve aceitar este termo antes de enviar qualquer imagem.
